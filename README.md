# Introduction
---
I have built a website for the Faith Independent Baptist Church organization that is a single page application using React, React Router, and Bootstrap. The site uses client-side routing using Netlify service to build and deploy the website. 

Test Site:
https://test-fibc-website.netlify.app/

# Setup 
---
Create Vite environment for React
```
npm create vite@latest
```
Install react dependencies
```
npm install react-router-dom

npm install bootstrap@latest
```
run project
```
npm run dev
```
build project
```
npm run build
```
